# Theme Store Compliance Notes

This scaffold addresses the structural baseline for a Shopify OS 2.0 theme:

- Required theme folders and config files
- Required template file names and formats
- `theme.liquid`
- Header and footer section groups
- A `Custom Liquid` section with a `liquid` setting
- JSON templates for section-based pages
- Baseline SEO snippet usage
- Localization selectors, menus, newsletter, cart notes, discounts, and basic payment icon output
- Product section architecture with individual blocks and `@app` support

This scaffold does not claim Theme Store compliance yet.

Work still required before submission:

- Original art direction and a clearly differentiated theme identity across all core templates
- Full product media UX, variant image switching, swatches, and robust product form behavior
- Predictive search implementation
- Full faceted filtering QA on collection and search templates
- Complementary products implementation and validation
- Rich product media QA for product, featured product, and quick-buy contexts
- Gift card recipient flow on gift card products
- Complete browser and webview QA
- Lighthouse benchmarking and optimization
- Accessibility auditing, keyboard-flow review, and contrast testing
- Real demo-store content and preset polish
- Social icon system refinement
- Thorough Theme Store submission review against every requirement
