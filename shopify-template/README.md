# Shopify Theme Store Scaffold

This folder is now a Shopify Online Store 2.0 theme scaffold aimed at Theme Store development.

Important:

- This is not a Theme Store-ready submission.
- It provides the required folder structure, mandatory template files, section groups, a custom liquid section, and baseline page implementations.
- A real Theme Store submission still needs deeper feature completion, a distinctive original art direction, benchmark testing, demo-store content, browser QA, accessibility review, and performance tuning.

Included:

- `layout/theme.liquid`
- Required templates in `templates/`
- Required config files in `config/`
- Header and footer section groups
- Core sections for homepage, page, contact, product, collection, cart, search, blog, article, password, 404, newsletter, and custom liquid
- A standalone `page.landing.json` alternate template
- Reusable snippets for SEO and cards

Use:

1. Copy the contents of this folder into a Shopify theme project.
2. Review [`COMPLIANCE.md`](/Users/gavynwitcher/Documents/New project/shopify-template/COMPLIANCE.md) before treating this as a submission baseline.
3. Finish the missing Theme Store requirements and test against Shopify's benchmark shops before submitting.
